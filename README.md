# Retro Poker

Aplikacija se nalazi u direktorijumu [`retro-poker/`](retro-poker/). Instalaciju,
pokretanje projekta i testove izvršavajte iz tog direktorijuma; detaljne komande su
u njegovom [`README.md`](retro-poker/README.md).

## Napomena o strukturi repozitorijuma

Ranija putanja `retro-poker-prefix/retro-poker/tests/integration/session.test.ts`
bila je napuštena kopija aktivnog testa iz
`retro-poker/tests/integration/session.test.ts` (razlikovala se samo po praznom redu).
Nije imala posebne reference ni ulogu u test komandama, pa je uklonjena da ne bi
postojala dva prividna projektna korena.
