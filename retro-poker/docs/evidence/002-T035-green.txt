Pokriven UI

- Status komponenta: off/on idle, waiting, retrying, model fallback, accepted model
  potez, local fallback, timeout, 429, provider error, cancelled, stale, missing
  config i semantic rejection. Status ima tekst i aria-live; loader ima accessible
  label.
- App povezuje server `lastBotOutcome` sa success/fallback porukom, ogranicava
  outcome na aktuelnu ruku, sinhrono zakljucava mutacije i odbacuje starije ili
  nepovezane polling rezultate. Zakasneli analysis `generating` odgovor ne pregazi
  terminalno stanje iste interakcije.
- Analysis panel: samo terminalna partija, loading/completed/failed/unavailable,
  rucni retry, validirani strukturisani rezultat, disclaimer i nepromenjen
  `HandResult`; nevalidan API/GameView odgovor se odbija runtime schemom.
- Dashboard: broj logickih zahteva, uspesni model zahtevi, local fallback, timeout/
  429/server/network/schema greske, prosecno trajanje i broj analiza; reset trazi
  potvrdu i salje ocekivanu reviziju. Tokeni se oznacavaju kao delimični kada deo
  metapodataka nedostaje, a cena kao nepoznata bez direktne provider vrednosti.
- API usage DTO odbija nepoznata polja, ukljucujuci potencijalno privatna polja.
- Postojece native buttons/inputs ostaju fokusabilni tastaturom; vidljivi
  `:focus-visible`, reduced-motion i responsive pravila na 760px/420px postoje.

Bezbednost i ogranicenja

Nije pokrenut nijedan live Gemini/API poziv i nijedan API kljuc nije trazen ili
ucitan za ovaj rad. Testovi koriste mock podatke i mock Gemini SDK.

Aktuelni backend `GET /api/ai/usage` trenutno vraca prazne `logical` i `attempts`
nizove i brojac nula; zato dashboard ispravno prikazuje prazno stanje dok backend
ne emituje stvarne agregate. UI-only scope nije prosiren na backend.

Javni `GameView` daje bot terminalni ishod samo kao `model` ili `local_fallback`, a
ne izvor greske. Zbog toga UI moze prikazati samo bezbednu genericku fallback poruku;
timeout, 429, provider error i semantic rejection tekstovi testiraju komponentu, ali
ne mogu se pouzdano povezati sa zivim bot ishodom bez prosirenja backend ugovora.
Live kvota, dostupnost modela, naplata i realna latencija nisu proverene.
